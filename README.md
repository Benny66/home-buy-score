
# 购房量化评分体系（HomeBuyScore-Vue）
一款基于Vue构建的现代化买房决策辅助工具，以组件化、响应式设计解决传统购房决策「感性模糊、流程杂乱、风险难控」的痛点，提供多场景专属评分模型。

## 核心功能
✅ 多场景适配：内置刚需、改善、二手房、异地购房4套评分模板，一键切换
✅ 量化评分体系：将预算适配、区域配套、房源品质、产权风险等因素转化为可计算分数
✅ 实时响应式交互：输入打分即时计算加权总分、维度得分，自动生成购房建议（强烈推荐/谨慎考虑/不建议）
✅ 自定义配置：支持可视化调整评分维度、权重占比，适配不同城市购房政策（如深圳、上海）
✅ 便捷实用：支持评分数据本地缓存、表格打印、导出Excel，适配移动端/桌面端
✅ 组件化复用：核心模块（评分表格、总分计算、结果展示）可独立复用

## 技术栈
- 前端框架：Vue 3（Composition API）
- 工程化：Vue CLI / Vite
- UI组件库：Element Plus（推荐）
- 样式：SCSS / CSS3（响应式布局）
- 工具：XLSX.js（Excel导出）、localStorage（本地缓存）
- 扩展：支持对接房产数据API、后端服务集成（如Node.js/Go）

## Vue版本优势
✨ 组件化架构：代码拆分清晰，便于维护和二次开发
✨ 响应式数据：无需手动操作DOM，打分交互更流畅
✨ 生态丰富：无缝对接UI库、导出工具，快速提升开发效率
✨ 跨端兼容：基于Vue的响应式布局，适配手机、平板、电脑多终端
